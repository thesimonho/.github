# Contributing

Read the README on the repository's main page for any setup or testing instructions. Search existing issues and pull requests before opening a new one.

For a bug report, describe what happened, what you expected, and how to see the same behavior. Include the version and environment where relevant. For a substantial change, discuss the problem in an issue or discussion before starting work.

Keep pull requests focused on one change. Explain why it is needed, link any related issue, and describe the checks you ran. If the change affects how people use a feature, update the relevant documentation.
